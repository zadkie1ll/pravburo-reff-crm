# Карта стадий Bitrix24

Снимок конфигурации production CRM на **01.09.2026**.

Документ фиксирует внутренние идентификаторы и названия Bitrix24. Колонки
«Публичное название», «Видимость» и «Группа прогресса» оставлены для отдельного
согласования интерфейса агента.

## Значения семантики

- `PROCESS` — промежуточная стадия; в ответе Bitrix поле `SEMANTICS` пустое.
- `SUCCESS` (`S`) — успешное завершение.
- `FAILURE` (`F`) — неуспешное завершение.

## Правила использования

1. Для связи сделки с исходной заявкой используется стандартное поле
   `Deal.LEAD_ID`.
2. Стадия лида определяется только по `Lead.STATUS_ID`.
3. Стадия сделки определяется парой `Deal.CATEGORY_ID` + `Deal.STAGE_ID`.
4. Названия из Bitrix не следует напрямую показывать агенту до заполнения
   публичной разметки: часть названий является внутренней терминологией.
5. Изменение названий или состава стадий в Bitrix не обновляет этот документ
   автоматически — карту нужно повторно сверить через API.

## Источник данных

- лиды: `crm.status.list`, фильтр `ENTITY_ID=STATUS`;
- сделки категории 0: `crm.dealcategory.stage.list`, параметр `id=0`;
- семантика финальных стадий сделки: `crm.status.list`, фильтр
  `ENTITY_ID=DEAL_STAGE`.
